# Roadmap

CEACStatusBot Web is an Alpha self-hosted project. The roadmap is intentionally conservative.

## Near Term

- Expand mocked portal fixtures and regression coverage.
- Improve operator observability for queue latency and portal outages.
- Add documented migration helpers for encrypted fields and SQLite backups.
- Extract portal adapters behind clearer service boundaries.

## Later

- Provide an optional Docker starter without replacing the current systemd deployment path.
- Add deployment profiles for small single-host installations.
- Improve accessibility and mobile QA coverage.

Portal integrations remain best-effort because external websites can change without notice.
